TUMBANG PRESO SLIPPER SOURCES

Every processed prop under Art/models is a derivative of one of the source files kept
beside this note. Two pipelines write them and they are NOT interchangeable:

  tools/build_slipper_models.py   the "src_" sources. Geometry, materials and textures
                                  go through UNTOUCHED. Only the pair split, a uniform
                                  scale to the game's 0.432 m and the seating move.
  tools/build_slipper_roster.py   the "source_" sources. The older pass, which also
                                  recolours to a flat palette and bevels the silhouette.

Delete a source the moment nothing builds from it. Both scripts write to the same
tsinelas_<id>.glb names, so a stale recipe silently overwrites the other one's output.

CHANGES BY THIS PROJECT
=======================

Old pass: isolated one shoe where a source contained a pair, normalised each prop to the
game's 0.432 m gameplay length, seated and centred the mesh, recoloured it to the game's
role-safe palette, and added a narrow bevel for the in-engine toon key light.

New pass: isolated one shoe, turned it onto its own long axis to point down +X, scaled
it uniformly to 0.432 m, and seated it. No recolour, no bevel, no decimation. Original
materials and textures are carried through.
