# Original street vendor sources

Blender5.2.1 LTS sources, authored by tools/author_street_stalls.py.
One unit is one metre. BlenderZ is up and -Y is the serving front; the imported
Unity serving face points+Z. The author preserves the source origin and supplies
feet/wheels, a supported umbrella and tools/stock at their point of use.

The owner's street-food, fruit and clothes/accessory photos informed construction
and use. No photographic pixels, watermarks, real shop branding or copied logos
are embedded. This does not license those reference photos as game textures.

Exported GLBs live in Assets/TumbangPreso/Art/models/street-stalls. MapPlaceAuthor
places them from the measured Ilalim plan, seats their actual bounds on pavement
and attaches static mesh collision. V2 invalid double-face indices were rejected;
current V3 reverses faces with separate vertices. See the map draft report for
actual player-camera review and route evidence, and remaining art limitations.
