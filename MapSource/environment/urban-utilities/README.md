# Retained neighborhood utility hardware

Derived from the existing env_post_electric.obj/mtl by tools/author_utility_posts.py.
The original files stay untouched. Eight connected6m span components are removed
from the derived hardware so EskinitaUtilityAuthor can connect the actual placed
insulators. Timber pole/crossarms,drum,insulators and coils remain. Wire hardware
uses a neutral dark material. The native Blender source carries5 explicit anchors.

Unity imports the hardware at1m units. The author preserves the12 original post
positions,orients their crossarms across the street,and builds50 separated44mm
circular conductors between matching anchors. Trunk collision comes from the
actual base vertices. Original pole instances remain inactive. These are editor
source models,not a new input or gameplay system. Verify actual views,physical
routes and repeatability after changes. No full performance claim is made from
vertex counts or a successful import alone.
