# Bayan passenger tricycle

Original clean blocky model authored by tools/author_terminal_tricycle.py.
The native .blend and exported .glb are generated from the same geometry. Run
Blender with that script and --publish only after reviewing versioned output.
The published asset is used by MapFinalPassAuthor only in Bayan's southern bay;
Ilalim retains its existing vehicles and interactive shop props.

A motorcycle, right-hand passenger sidecar, open entry, broad windscreen and canopy
establish the vehicle through construction. Oxblood paint, warm neutral canopy,
brushed sheet metal and dark rubber avoid role-blue/role-orange decoration.
No logos, copied decals, normal maps, tiny spokes or moving vehicle gameplay.
The mesh has608 source vertices,544 source faces and7 material groups.

Visual reference for the motorcycle/covered-sidecar relationship:
Eva Rapoport's original [Living Amongst the Dead photo series](https://jathilan.me/living-amongst-the-dead).
No source photograph or third-party mesh is embedded in the asset.

Study renders: Logs/terminal-tricycle-v1/front.png and back.png.
Unity review: Logs/map-owner-composition-v9, both modes and all3 profiles.
These are static scenery beyond the playable boundary, with space between parked
vehicles and their trunks moved behind the bay. No invisible reachable obstacles.
