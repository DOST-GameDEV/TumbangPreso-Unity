# Details for retained chunky houses

These construction studies preserve the existing licensed Kenney city houses a/c.
The native Blender files contain that retained reference for comparison. Exported
GLBs contain only the new detail meshes. Existing license/provenance remains in
the source kits under Assets/TumbangPreso/Art/models/kits/city.

Author:tools/author_retained_house_details.py, Blender5.2.1 LTS. The source body is
reviewed at its existing5x world scale. Exported details are in metres; a detail
instance parented to the original5x Unity body uses localScale0.2, localPosition0.

Preserve body/roof/deep-frame mass. Jalousies fit actual window panes. The lower
house has a small service window; only the taller house gets a supported entrance
shade. V1's low-house canopy covered its transom and was rejected. Current V2
omits that unnecessary canopy. Reserve the projecting entry's private setback
before map use. No detail set is currently placed in a map.

NeighborhoodBuildingReview compares retained and detailed forms with approved
Tikboy. Its8 Editor construction views are not a complete FPP/ordinary-play or
artistic acceptance. Thin replacement house V1-V5 studies are rejected separately
and must not be revived; they are preserved locally under Logs/rejected-thin-house-studies.
