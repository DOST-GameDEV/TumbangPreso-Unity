# Cloud source provenance

These four unmodified 2K HDR panoramas were downloaded from Poly Haven for TUMP's
map sky refinement. The shader uses cloud form and normalized shading while the
maps retain their authored sky colors, horizon haze and directional sunlight.
They are original sky inputs, not replacement buildings or map photographs.

- Kloofendal 38d Partly Cloudy Pure Sky: Greg Zaal (original), Jarod Guest (sky edits).
  https://polyhaven.com/a/kloofendal_38d_partly_cloudy_puresky
- Kloofendal 48d Partly Cloudy Pure Sky: Greg Zaal (original), Jarod Guest (sky edits).
  https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky
- Kloppenheim 03 Pure Sky: Greg Zaal (original), Jarod Guest (sky edits).
  https://polyhaven.com/a/kloppenheim_03_puresky
- Wasteland Clouds Pure Sky: Sergej Majboroda (original), Jarod Guest (sky edits).
  https://polyhaven.com/a/wasteland_clouds_puresky

Provider license: CC0 1.0, https://polyhaven.com/license . Exact URLs, byte counts,
provider MD5 and local SHA256 are recorded in provenance.json. Source files have
not been repainted or resized. Unity's generated import copies have their own
compression/mipmap settings and preserve these bytes. The game does not call the
Poly Haven API at runtime. No login, API key, paid service or reset was used.

The fully procedural sky drafts were visually rejected; their evidence remains
in docs/reports/full-backlog-2026-09-21 and validation Logs.
