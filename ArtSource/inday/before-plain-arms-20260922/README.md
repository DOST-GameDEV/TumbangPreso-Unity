# Inday source before plain arms

The owner explicitly requested removal of Inday's pogo-like arm attachments and
plain brown arms in all models on 2026-09-22. These unmodified source backups
preserve the earlier choice. Production model GUIDs, rigs, non-arm geometry and
all animation samples remain intact. `tools/inday_plain_arms.py` records before /
after hashes and removes only arm-owned attachments. Do not restore these older
guards over the newer instruction. First-person arms are baked from the new body.
