# Tutorial bot policy

The tutorial roster now selects a distinct character for every seat, starting
after the student's selected character. Ordinary matches retain their existing
selection. Tutorial bots no longer produce Ultimate input; their ordinary skills
and the student's ultimate remain available. No kit mechanics or bindings changed.
