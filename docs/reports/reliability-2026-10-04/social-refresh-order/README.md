# Friends actions survive older refresh replies

acknowledged list. It could erase an accepted friend or revive a removed one.

followed by an older load could replace the cache without asking for a fresh read.

Advance a list-write version when a write starts. Earlier loads retain the
newer list and schedule a fresh read. New loads defer while writing. Existing
owner fences, primary/guest cache isolation and the shipping REST path remain.
