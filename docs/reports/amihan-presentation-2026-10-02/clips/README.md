# Silent Airburst review clips

All four clips are 29.233 seconds, 1280x720, with no audio stream. Each contains
two complete 11-second normal-speed passes, followed by a labelled 0.4x section
from game time 4.3 to 7.2 seconds. The four views are owner, observer outside the
fan, victim inside the fan and court. Original game time stays on screen.

- [Before, effects](airburst_before_effects_v1.mp4): B2 shipped baseline. Its
  invalid observer view is replaced by a labelled blank. Use court/victim views.
- [After, effects](airburst_after_effects_f3.mp4): final F3 native frames.
- [After, live effects hidden](airburst_after_body_f3.mp4): final F3 body review.
  This hides the live fan; the introduction still contains its authored effects.
- [After, Low quality](airburst_after_low_f3.mp4): final F3 Low variant.

These are rendered fixed-simulation films at 30 frames per game second, not
real-time performance or actual-peer qualification. No SFX was added or judged.
The packaging check verifies duration, silent streams and representative labelled
frames, not human approval of the motion. `media-receipts.json` records hashes.

The final observer framing still contains a large nearby head, and the victim
view is similarly crowded. These views prove the fixture's inside/outside state
checks but limit visual readability review. The court view is clearer. Selected
F3 frames show faint mint fan strokes on the light court and a close introduction
shot with some face cropping. Review both normal-speed passes before deciding
the next feel changes; do not treat automated pass results as composition approval.
