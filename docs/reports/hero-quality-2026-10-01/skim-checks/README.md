# Skim gameplay unit

The attacking Hydro role replaces live Mirrorwake with the published eight-second
held-slipper load and 35 second cooldown. The load belongs to the actual held
slipper. Empty hand, drop, expiry, replacement, role change and round reset cannot
retain a grant for a later pickup. A real Carrier release consumes it once.

On first genuine ground contact, the host continues the same throw for at most
two metres at five metres/second. It stays in flight during this brief phase and
then enters the ordinary loose/landed state. No new throw or score chain is made.
The same host body/can contact code remains active. Solid cover, unsupported or
steep floor and playable bounds stop the slide. Round interruption retires it.
Ground skimming is excluded from Crosscurrent's airborne targets, avoiding an
interception that would be overwritten by the slide's next step.

Protocol116 appends Skim affinity5 and changes the role semantics. Existing
slipper state/pose messages carry the motion; timed-kit recovery restores the
load after held equipment, without recasting or spending resources. Its first
recovery latch resets at a new round. Generic scope/order gates remain intact.
Historical Mirrorwake world/replay decoding and inactive saved sidegrade IDs stay
available; the live role no longer creates a decoy. No input or score rewrite.
