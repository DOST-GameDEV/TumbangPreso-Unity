# Crosscurrent implementation unit

Implements the published Hydro signature's 35 second cooldown instead of the
legacy two charges. Stable ability ID, current cast/body/FPP routes and bounded
40 degree bend remain. Range/gather/footprint now use engine-free RafiRules.
Other Hydro abilities and the complete presentation pass remain unfinished.

## Contact fairness

The previous resolver stopped on the first qualifying item in its scene-derived
shoe array. That was not necessarily the first contact in the physics interval.
The replacement intersects relative motion against the finite current cylinder,
combining horizontal entry/exit with its vertical interval. It chooses the earliest
eligible in-flight slipper, with owner slot breaking exact equal-time contacts.
The existing HostSteerFlight retains horizontal speed, owner, throw credit, spin,
affinity and shot state. A held/loose slipper is not eligible. Solid-cover refusal
and the spent-current snapshot/presentation route remain unchanged.

This unit does not add a fake hit or a new flight, change scoring, or let a replay
steer gameplay. Protocol115 separates the new cooldown/contact semantics from114;
existing cast-resource/world/slipper replication formats are retained. Current115
actual peers and complete Hydro art/audio remain separate qualification work.

## Checks

Four pure Core cases pass: published values, first-entry ordering, overlapping
vertical/horizontal intervals, and stationary/invalid input. The first dotnet
launch used the read-only default CLI home; the corrected writable setup home
ran the same tests. This was tooling setup, not a product failure.

Native baseline fails the earlier-contact expectation with reversed shoe inventory.
The final native run checks both inventory orders on real airborne slippers and
the existing moving-current flight/credit test with cooldown spending/refusal.
Final two native cases pass, with all frozen inputs unchanged and no new OOM.
Publication follows these focused results; no whole-kit completion claim.
No new cover, actual-peer, physical-device, normal-speed film or audio claim.
