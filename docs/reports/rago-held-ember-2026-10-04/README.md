# Rago held-ember readability

Small, render-only refinement of Empowered Throw's existing three shoe-attached
flame tongues. Baseline first-person frames showed narrow detached-looking orange
splinters. The candidate widens the authored forms, lowers their bases onto the
shoe, and warms the toe colour while retaining visible shoe leather/buckle.

Only SeanIgnitionVisual changes in production. Same three renderers, geometry
construction, heights, seed, age-only flicker and actual mesh-bound scaling.
No particles, colliders, timings, affinity, cooldown, authority, animation, sound
or replicated state changed. No finalized character was modified.
